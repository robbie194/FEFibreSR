# 二维重建结果疑问与论文级仿真路线

本文回答 `phase2_xy_sigma0` 和 `phase2_xy_sigma08` 结果中最关键的四个问题，并据此界定当前仿真已经证明的内容、尚未证明的内容，以及下一阶段应优先完成的实验。

相关结果位于：

```text
isl_diff_event_clean/results/fibre_neurosr/phase2_xy_sigma0/
isl_diff_event_clean/results/fibre_neurosr/phase2_xy_sigma08/
isl_diff_event_clean/results/fibre_neurosr/phase2_xy_sigma_sweep/
```

## 问题 1：为什么 sigma=0.8 和 sigma=0 的重建看起来几乎没有差异？

### 直接回答

在其他条件相同时，`sigma=0.8 um` 理论上应当比 `sigma=0` 稍差。当前结果实际上也是稍差，只是差距没有大到肉眼一眼就能看出来。

两组联合重建的正式结果为：

| 指标 | sigma=0 | sigma=0.8 | sigma=0.8 相对变化 |
|---|---:|---:|---:|
| 事件总数 | 137,167 | 102,961 | -24.9% |
| PSNR | 18.413 dB | 18.240 dB | -0.173 dB |
| SSIM | 0.7999 | 0.7879 | -0.0120 |
| 图像相关性 | 0.9341 | 0.9315 | -0.0027 |
| x 梯度相关性 | 0.4604 | 0.4527 | -0.0077 |
| y 梯度相关性 | 0.4331 | 0.4064 | -0.0267 |

因此不能说两者完全相同。`sigma=0.8` 使边缘随时间的变化减弱，事件数减少约四分之一，联合结果的所有主要指标也都有所下降，其中 y 梯度下降最明显。

### 为什么差别仍然很小

#### 1. 当前系统本来就有更强的共同限制

即使 `sigma=0`，每个纤芯仍然对直径 `2.9 um` 的圆形孔径做空间积分，纤芯间距为 `4.5 um`。GRIN blur 不是系统中唯一的低通因素，芯孔径积分、稀疏芯采样、有限运动轨迹和重建正则都在限制高频恢复。

`0.8 um` 相对 `4.5 um` 的芯间距不是极大的模糊，但也绝对不能忽略。Gaussian `sigma=0.8 um` 对应的 FWHM 约为：

$$
2.355\times0.8
\approx1.88\ \mathrm{um}.
$$

作为尺度直觉，半径 `1.45 um` 的均匀圆孔径在单个坐标轴上的标准差为约 `1.45/2=0.725 um`；若暂时把两者近似成可按方差相加的低通尺度，加入 GRIN blur 后约为：

$$
\sqrt{0.725^2+0.8^2}
\approx1.08\ \mathrm{um}.
$$

真实圆孔径并不是 Gaussian，因此这不是精确等效 PSF，只用于说明 `0.8 um` 是有意义的退化。事件数减少 24.9% 也直接证明它已经明显改变了观测。视觉差距仍然小，主要原因是下面的 exact-model 反演，而不是 `0.8` 本身没有作用。

#### 2. 重建使用了正确且已知的 sigma

仿真与重建都读取同一配置中的 `grin.sigma_um`。重建前向顺序为：

```text
远端物体与位移采样
  -> GRIN Gaussian PSF
  -> 圆形纤芯孔径积分
  -> 每芯 APS 和事件预测
```

`sigma=0.8` 真值经过可微前向模型后的 core signal 与 simulator 的相关性为 `0.999999`。这说明代码没有漏掉 `0.8`，而是利用已知 PSF 对可恢复频率做了反卷积补偿。

#### 3. 当前条件接近“同模型、无噪声”的理想逆问题

当前 phase 2 配置中：

```text
threshold_sigma = 0
shot_noise_rate = 0
leak_rate = 0
refractory_period = 0
relay PSF sigma = 0
运动和 GRIN sigma 完全已知
```

生成数据和重建数据的模型高度一致，这在方法验证阶段是合理的，但属于比较乐观的 exact-model 条件，也常被称为需要警惕的 inverse crime。已知模糊、没有噪声和没有标定误差时，算法自然能补偿相当一部分 `sigma=0.8` 的退化。

#### 4. 显示目标是高对比度二值图样

USAF 图样的大结构在两种情况下都很稳定。差异主要集中在细条纹、边缘斜率和低对比小结构上，而不是大轮廓上。因此共同灰度范围下的整图视觉差异会比频域指标或局部线剖面更小。

### 结论

当前现象是合理的，但它也暴露出下一步必须补做的实验：不能只比较 `0` 和 `0.8` 两个点，也不能只做正确 PSF 的无噪声反演。至少需要增加连续 sigma sweep、错误 sigma 重建和噪声条件，才能得到有说服力的“模糊程度与可恢复分辨率”曲线。

## 问题 2：为什么 events-only 的细节与联合重建接近，只是整体更暗？

### 直接回答

这是合理的，而且正好体现了事件信息的优势与根本缺陷：

- 事件非常擅长约束结构变化、边缘位置和相对对比度；
- 事件不能可靠确定绝对亮度、DC 分量和全局强度尺度；
- APS 提供的主要补充正是绝对亮度和低频强度锚点。

以 `sigma=0` 为例：

| 结果 | 平均亮度 | 标准差 | 与 GT 相关性 | PSNR | APS 重投影 RMSE | 事件残差 MAE |
|---|---:|---:|---:|---:|---:|---:|
| GT | 0.8137 | 0.3350 | 1.000 | - | - | - |
| Events-only | 0.2890 | 0.1112 | 0.8850 | 4.76 dB | 0.5575 | **0.0219** |
| APS + events | 0.8138 | 0.3022 | **0.9341** | **18.41 dB** | **0.0081** | 0.0282 |

Events-only 的相关性较高，说明它确实恢复了很多结构；但其平均亮度只有 GT 的约三分之一，APS 重投影完全错误，因此它不是与联合重建等价的结果。

### 为什么事件能恢复轮廓和部分低频结构

当前事件损失使用累计 lin-log 变化：

$$
\Delta L_i(t)
=
L(c_i(t))-L(c_i(0)).
$$

在对数响应区，如果全部强度乘以常数 $a$，则：

$$
\log(a c_i(t))-\log(a c_i(0))
=
\log(c_i(t))-\log(c_i(0)).
$$

所以事件对全局乘法尺度近似不敏感。低亮度时 v2e 使用线性响应，因此这种不确定性不是数学上处处严格成立，但整体亮度仍然是很弱的约束方向。

远端物体沿 L 形轨迹扫过固定纤芯时，大轮廓的进入、离开和宽缓亮度变化也会产生时间事件。事件并非只包含最高频边缘；只要一个空间结构在扫描过程中引起芯通光量变化，它就会出现在事件约束中。两段非共线运动又分别提供了 x、y 方向变化，因此 events-only 能恢复相当完整的轮廓。

TV 正则还会把这些沿轨迹获得的变化约束连接成连续区域。这就是为什么低频轮廓看起来也不错，但它的整体基线仍然落在错误亮度上。

### 为什么 events-only 的事件残差反而更小

Events-only 只需要解释事件，可以利用亮度尺度零空间选择一个更容易拟合事件的暗解。联合重建必须同时解释 APS、事件并满足 TV 正则，三种要求之间存在小的折中，所以联合结果的事件残差略高并不矛盾。

### 后续应该怎样评价 events-only

应同时报告两组指标：

1. 原始强度指标：不做亮度校正的 PSNR、SSIM、APS 重投影误差；
2. 结构诊断指标：相关性、梯度相关性，以及对 events-only 做一次最优仿射亮度对齐后的结构指标。

仿射对齐只能用于回答“事件恢复了多少结构”，不能把对齐后的结果冒充 events-only 已经恢复了绝对强度。

## 问题 3：联合重建仍然与 GT 差距较大，合理吗？与原始 GT 比较是否公平？

### 直接回答

差距是合理的。与原始 GT 比较是一个有效但非常严格的 end-to-end 指标；它不应被删除，但不能作为唯一评价。

当前对比已经只在所有纤芯和运动共同覆盖的 observable crop 内计算，并且 GT 从未进入重建损失，所以不存在用不可见边界拉低指标或真值泄漏的问题。

真正需要注意的是：GT 和重建虽然最终都显示成 `400 x 400`，但二者的自由度并不相同。

### 当前重建本身只有 112 x 112 个潜变量

GT 的采样间隔为 `0.5 um`，尺寸是 `400 x 400`。当前重建先优化 `112 x 112` 的 latent image，再双线性扩展到 `400 x 400`。潜变量对应的名义网格约为：

$$
\frac{400\times0.5}{112}
\approx 1.79\ \mathrm{um}.
$$

直接使用 GT 优化同一个 `112 x 112` 潜变量，而不经过光纤、事件和 APS 逆问题，得到的经验 oracle 结果也只有：

```text
PSNR:        19.67 dB
SSIM:         0.834
correlation:  0.951
```

当前 `sigma=0` 联合结果为 `18.41 dB / 0.800 / 0.934`。也就是说，约 `1.25 dB` 是联合反演相对该潜变量 oracle 尚未恢复的差距，而大量肉眼可见的 GT 细线差异，本身已经受到 `112 x 112` 表示能力限制。

这个 oracle 是数值优化得到的经验参照，不是严格数学上界，但足以说明不能把扩展后的 `400 x 400` 显示尺寸误认为算法真的拥有 `400 x 400` 个独立自由度。

### 还有哪些不可逆或欠定因素

1. `2.9 um` 圆形芯孔径先对物体做空间积分；
2. 纤芯中心间距为 `4.5 um`，原始空间采样较稀疏；
3. L 形轨迹只经过两条一维路径，不是完整覆盖二维面积的 raster scan；
4. 事件阈值为 `0.2`，事件测量经过阈值量化；
5. 重建每 5 个仿真时间点使用一次事件，即有效间隔为 `0.5 ms`；
6. TV 权重为 `0.005`，会主动牺牲部分细纹以抑制蜂窝伪影和不稳定解；
7. 某些高频已经被 GRIN PSF 和芯孔径压到接近零，正确模型也不能从零信息中恢复它们。

因此“联合重建明显优于 APS-only”与“联合重建仍达不到理想 GT”可以同时成立。

### 更公平、也更完整的评价方式

后续应同时保留以下四层评价：

1. **原始 object GT**：最严格的 end-to-end 指标，不能删，也不能只换成模糊 GT；
2. **同参数化 oracle GT**：使用同样 latent shape 直接拟合 GT，分离表示能力上限与反演损失；
3. **光学可辨识 GT**：将 GT 投影到已知光学和采样可恢复带宽，用于判断算法是否接近系统信息上限；
4. **观测域一致性**：APS 重投影、事件残差和留出时间点预测，证明结果确实解释了测量。

对于 USAF 图样，还应增加 line profile、Michelson contrast、可分辨 group/element 和方向性 MTF，而不是只依赖整图 PSNR/SSIM。

只与模糊后的 GT 比会让结果显得更好，却可能掩盖没有真正恢复高频的问题；只与原始 GT 比又会把物理上不可恢复的频率全部算成算法错误。四层评价一起报告才公平。

## 问题 4：怎样让仿真足以支撑论文，并可靠过渡到真实实验？

### 当前工作处于什么阶段

当前结果已经是一个完整的 proof of principle：

- 从远端运动、GRIN、纤芯、relay、APS 到 v2e events 的全链路存在；
- 二维非共线运动相对纯水平运动显著提高 y 方向梯度恢复；
- `sigma=0` 和 `0.8` 均由一致的物理前向解释；
- APS-only、events-only 和联合重建验证了两种观测的互补性。

但它还不足以单独支撑强论文结论，因为目前只有一个 USAF target、一个随机种子、一个 L 形轨迹、两个 sigma 点，而且噪声、标定误差和模型失配基本为零。当前最可靠的结论是“exact-model 条件下方法可行”，还不能直接推出真实系统中同样有效。

如果希望仿真本身成为有说服力的论文章节甚至独立论文，还需要先把科学问题写成可证伪的假设，而不是只追求更多重建图。例如：

1. 在相同曝光、路径长度和事件预算下，二维事件联合重建是否显著提高方向性 MTF；
2. 增益在多大的 GRIN blur、事件噪声和运动误差范围内仍然成立；
3. 哪种微扫描轨迹的信息效率最高，是否存在最优位移幅度；
4. 用独立高保真生成器得到的数据，能否被较简单的重建模型稳定解释；
5. 仿真预测的性能排序和退化趋势，能否在真实标定系统中复现。

后面的实验设计都应服务于这些假设，并给出置信区间、失败条件和与公开方法的比较。

### 第一优先级：消除 inverse crime，建立评价上限

这是最重要的一步，比继续生成更多相似图片更有价值。

1. 使用更高分辨率生成模型，例如 `0.125 um` 网格，而重建仍使用当前较粗模型；
2. 生成端与重建端使用不同的 PSF 离散、边界处理和孔径实现；
3. 增加 latent oracle、光学带限 oracle 和 observation oracle；
4. 将时间点分成训练与留出集合，在未参与优化的时间点验证 APS/event 预测；
5. 明确区分 oracle known-parameter 与 estimated-parameter 两种结果。

只有生成模型比重建模型更丰富，才能证明算法不是因为“知道答案由哪个精确程序生成”才表现良好。

### 第二优先级：做受控的鲁棒性和失配实验

建议至少扫描：

| 因素 | 建议设置 |
|---|---|
| GRIN sigma 真值 | `0, 0.4, 0.8, 1.2, 1.6 um` |
| 重建 sigma 误差 | 真值的 `-30%, -15%, 0, +15%, +30%` |
| 事件阈值 | 多档均值，并加入 pixel/core 间阈值离散 |
| 事件非理想 | shot noise、leak、refractory、有限 bandwidth、hot pixels |
| APS 非理想 | shot noise、read noise、dark offset、PRNU、饱和 |
| 纤芯非理想 | gain 变化、芯位置误差、直径变化、dead cores、串扰 |
| 运动误差 | 位移噪声、速度波动、回程间隙、时间同步偏差 |

每个关键条件至少使用 5 到 10 个随机种子，报告均值、标准差、置信区间和失败率，不能只展示最好的一次。

### 第三优先级：公平比较不同运动轨迹

至少比较：

```text
静止
x-only
对角直线
L 形
小圆
raster
Lissajous 或随机微扫描
```

比较时必须控制总曝光时间、总路径长度、最大位移和事件总预算，否则“更长轨迹产生更多信息”会被误认为“轨迹形状更好”。

还应扫描位移幅度，例如 `0.25、0.5、1、2` 个 core pitch，并绘制 x/y 分辨率与运动幅度、速度、事件率之间的关系。

### 第四优先级：扩展 target 和评价指标

目标图像至少包括：

- USAF：离散线对分辨率；
- Siemens star：方向性与各向同性分辨率；
- slanted edge：MTF50、MTF10；
- 点和细线：PSF/LSF 与定位误差；
- 自然图像：非二值纹理；
- 与计划真实实验一致的生物或荧光样本。

指标至少包括：

- PSNR、SSIM、相关性；
- x/y 梯度和方向性频谱；
- MTF、FRC 或 line-pair contrast；
- APS/event 留出集重投影误差；
- event rate、运行时间和显存；
- 多随机种子的统计显著性。

### 第五优先级：补齐 baseline 和 ablation

除了现有三组结果，还应加入：

1. 直接芯插值；
2. 常规多帧 super-resolution；
3. 只使用瞬时/短曝光 frames 的理想上界；
4. 已知运动与估计运动；
5. 正确 sigma、错误 sigma 和不建模 sigma；
6. 有/无 TV，不同 latent resolution；
7. 有/无事件、有/无 APS、有/无 core aggregation；
8. 与公开 event-based reconstruction/SR 方法在相同输入上的比较。

Ablation 的目标不是让每个模块都显得有用，而是明确每项物理假设在什么条件下有效、何时失效。

### 第六优先级：让仿真成为真实系统的 digital twin

真实光学系统可以在设计阶段尽量匹配仿真参数，但不能只做“让真实系统服从理想仿真”这一件事。芯位置、PSF、阈值和运动误差都有制造与装调偏差，最终必须将实测参数反向写回 simulator。正确闭环是：

```text
理想仿真指导光学设计
  -> 搭建真实系统
  -> 独立标定实际参数
  -> 更新为 calibrated simulator
  -> 用未参与标定的数据验证预测能力
```

真实实验开始前，应按以下顺序标定：

1. 纤芯中心、直径、有效区域、dead cores 和每芯 transmission；
2. GRIN 的 magnification、distortion 和随视场变化的空间变 PSF；
3. relay PSF、sensor pixel integration、暗场和 APS gain；
4. 每个事件 pixel 的正负阈值、background activity、refractory 和 latency；
5. 远端运动轨迹、时间戳与 APS/event 同步；
6. 使用未参与标定的已知 target 验证完整前向，而不是在同一 target 上边调边测。

如果真实系统使用相干照明，还必须建模相位、speckle、模式耦合和弯曲敏感性；如果是空间非相干荧光，可以继续使用强度 PSF 框架，但仍需验证芯间串扰和模式变化是否能被标量 per-core 模型描述。照明相干性必须在论文中明确，不能混用两类物理模型。

### 推荐的实际执行顺序

下一阶段不建议一开始就把所有因素做成巨大笛卡尔积。更有效的顺序是：

1. 增加 oracle、频域/USAF 指标和留出时间点评价；
2. 做 `sigma truth x sigma reconstruction` 失配矩阵；
3. 加入真实量级的 event/APS noise、芯参数误差和运动误差；
4. 在等曝光、等路径长度下比较多种二维轨迹；
5. 用多 target、多 seed 重复最有代表性的条件；
6. 用真实标定参数替换理想参数，完成 synthetic-to-real 验证。

前两步用于建立信息上限和模型敏感性；第三、四步决定方案是否具有工程价值；第五步提供统计可信度；第六步才真正连接真实实验。

## 最终判断

四个观察都很重要，而且判断方向基本正确：

1. `sigma=0.8` 应当更差，当前也确实更差，只是 exact-model 和无噪声条件让差距被部分反卷积补偿；
2. events-only 恢复结构但丢失绝对亮度是合理现象，不能只看轮廓相似就认为它与联合重建等价；
3. 原始 GT 是必要的严格评价，但必须配合同参数化 oracle、光学带限评价和观测域一致性；
4. 当前仿真适合作为方法可行性起点，下一步的核心不是继续展示单张漂亮结果，而是消除 inverse crime、量化鲁棒性、做公平 baseline/ablation，并用真实标定参数建立 digital twin。
