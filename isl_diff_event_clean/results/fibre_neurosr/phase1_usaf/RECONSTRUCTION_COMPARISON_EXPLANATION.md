# reconstruction_comparison 各列结果及其物理意义

## 1. 这张图应该怎样阅读

对比图位于：

```text
isl_diff_event_clean/results/fibre_neurosr/phase1_usaf/
reconstruction_comparison.png
```

图中从左到右依次是：

1. `Truth (evaluation only)`：仿真真值；
2. `APS interpolation`：纤芯 APS 直接插值；
3. `APS only`：只使用 APS 的物理模型反演；
4. `Events only`：只使用事件的重建；
5. `APS + core events`：APS 和逐芯事件联合重建。

五列显示的是同一远端物体区域，使用相同空间范围和 `0~1` 灰度范围，因此可以直接比较结构、亮度和清晰度。

这里显示的是远端物体坐标中的连续图像估计，不是近端 DAVIS sensor 图，也不是把圆形芯斑直接放大后的图。

## 2. Truth：仿真真值

第一列来自：

```text
fibre_frame_event_sim/outputs/phase1_usaf/
00_source/object_intensity.npy
```

它表示仿真中真正的远端物体强度：

$$
O(x,y).
$$

真值只用于：

- 优化开始前检查可微前向模型是否与 simulator 一致；
- 优化结束后计算 PSNR、SSIM 和相关系数；
- 在对比图中提供视觉参考。

它没有进入重建损失，也没有用于初始化联合重建。因此后面的重建结果不是从真值复制出来的。

## 3. APS interpolation：纤芯 APS 直接插值

### 3.1 怎样得到

首先根据固定的近端芯斑位置，为每根纤芯选择 4 个增益高、归属明确且不重叠的 DAVIS pixels。

对这些 pixels 的 APS 值除以标定 gain，再在同一根纤芯内取中位数，得到 1415 根纤芯各自的曝光平均强度。

第 $i$ 根纤芯的 APS 测量近似为：

$$
\bar c_i=
\frac{1}{T}
\int_0^T c_i(t)\,dt.
$$

然后将每根纤芯的平均强度放在曝光中点对应的物体位置上，通过普通空间插值得到连续图像。

### 3.2 物理意义

这一列可以理解为：

> 把一张长曝光 APS 当作每根纤芯一个灰度值，然后直接填补六角纤芯之间的空隙。

但是，每个灰度值已经同时包含：

- 2.9 um 圆形芯孔径的空间积分；
- 25 ms APS 曝光积分；
- 曝光期间 4.5 um 水平运动造成的平均。

直接插值并不知道这些值是怎样形成的，也没有反演芯孔径或曝光运动。因此图中仍能看到六角采样造成的周期性明暗、锯齿和模糊。

其评价指标为：

```text
PSNR:        14.76 dB
SSIM:         0.611
correlation:  0.835
```

## 4. APS only：只使用 APS 的物理模型反演

### 4.1 怎样得到

这一列不是普通插值，而是优化一张连续远端物体，使它经过完整可微前向模型后，重新生成的 core APS 与真实观测一致。

前向过程为：

```text
待恢复远端物体
  -> 已知水平运动
  -> GRIN成像
  -> 2.9 um圆形芯孔径积分
  -> 1415根固定纤芯
  -> 25 ms曝光平均
  -> 预测core APS
```

主要损失为：

$$
\mathcal L_{APS}
=
\frac{1}{N}
\sum_i
\left(
\bar c_i^{pred}-\bar c_i^{obs}
\right)^2
+\lambda_{TV}\mathcal L_{TV}.
$$

其中 TV 正则用于抑制欠定逆问题产生的周期芯格纹理。

### 4.2 物理意义

APS-only 知道：

- 每根纤芯的准确位置；
- 芯孔径的大小；
- 远端物体的运动轨迹；
- APS 是一段时间积分，而不是瞬时图像。

因此它能够做一定程度的去蜂窝、去孔径模糊和运动反演，明显优于直接插值。

但是，一根纤芯最终仍然只有一个曝光平均值。许多不同的时间变化都可能产生相同的平均值，因此只使用 APS 时仍然存在较大的零空间，细小结构恢复不充分。

其评价指标为：

```text
PSNR:        15.76 dB
SSIM:         0.728
correlation:  0.869
```

## 5. Events only：只使用事件重建

### 5.1 怎样得到

这一列只使用按纤芯聚合后的 ON/OFF 事件，不使用 APS 图像结构进行初始化。

代码故意从一张常数 `0.5` 图像开始优化，避免把 APS 的绝对亮度和结构偷偷带入 events-only 基线。

对于第 $i$ 根纤芯，累计事件近似测量：

$$
\ell(c_i(t))-\ell(c_i(0))
\approx
C_+N_i^+(t)-C_-N_i^-(t),
$$

其中：

- $c_i(t)$ 是该纤芯在时刻 $t$ 的总通光量；
- $\ell$ 是与 v2e 一致的 lin-log 响应；
- $N_i^+(t)$ 和 $N_i^-(t)$ 是累计 ON/OFF 事件数；
- 当前正负事件阈值均为 `0.2`。

### 5.2 物理意义

事件记录的是：

> 当远端物体水平扫过固定纤芯孔径时，每根纤芯总通光量如何随时间增加或减少。

所以 events-only 可以恢复许多边缘、条纹和相对结构。其结构相关系数仍达到约 `0.819`，说明事件确实包含物体信息。

但是事件主要测量亮度变化，不直接测量绝对亮度。特别是在对数响应区域，把全部强度乘以一个常数时，事件变化可能基本保持不变。

因此 events-only 存在绝对 DC 和亮度尺度不确定性。对比图中整体偏灰、亮度与真值不一致，就是这一物理零空间的表现。

其评价指标为：

```text
PSNR:                  4.83 dB
SSIM:                   0.465
correlation:            0.819
APS reprojection RMSE:  0.551
```

PSNR 较低不意味着事件没有结构信息，而是说明事件不能单独决定整幅图的绝对灰度。

## 6. APS + core events：联合重建

### 6.1 怎样得到

这是当前应当使用的正式结果。

它同时要求待恢复物体满足：

1. 曝光积分后与观测 core APS 一致；
2. 随已知运动产生的每芯 lin-log 变化与累计事件一致；
3. 在纤芯之间保持合理连续，不产生六角周期纹理。

总损失为：

$$
\mathcal L
=
\mathcal L_{APS}
+0.03\mathcal L_{event}
+0.0015\mathcal L_{TV}.
$$

三部分的作用分别是：

```text
APS     -> 绝对强度、低频内容和整体亮度锚
Events  -> 曝光期间的时间变化、边缘和水平扫描采样相位
TV      -> 抑制六角芯格纹理和欠定解中的周期伪影
```

### 6.2 物理意义

APS 与事件的信息是互补的：

- APS 告诉算法每根纤芯在整段曝光中的平均通光量；
- 事件告诉算法这个通光量在曝光期间是怎样变化的。

因此联合结果既不会像 events-only 那样丢失绝对亮度，又比 APS-only 多出了沿扫描轨迹的时间变化约束。

其评价指标为：

```text
PSNR:        17.16 dB
SSIM:         0.767
correlation:  0.907
```

联合结果的事件残差 MAE 为 `0.0246`。将仿真真值送入同一个事件模型时，残差 MAE 为 `0.0248`。两者接近，说明联合重建已经把事件解释到 v2e 阈值量化允许的误差量级，而不是只得到一张视觉上相似、却无法解释事件的图。

## 7. 为什么事件可以提供额外空间信息

第 $i$ 根纤芯在时刻 $t$ 的强度为：

$$
c_i(t)
=
\int
A_i(\mathbf u-\mathbf r_i)
O(\mathbf u-\mathbf s(t))
\,d\mathbf u.
$$

其中：

- $O$ 是待恢复的远端物体；
- $A_i$ 是第 $i$ 根纤芯的圆形入口孔径；
- $\mathbf r_i$ 是固定纤芯中心；
- $\mathbf s(t)$ 是远端物体的已知位移。

纤芯和近端芯斑都没有移动，移动的是远端物体。随着 $\mathbf s(t)$ 改变，同一根纤芯孔径在物体坐标中观测了不同位置。

因此：

```text
APS     给出整段扫描的平均通光量
Events  给出扫描途中通光量怎样变化
```

把二者结合，相当于把一根纤芯的单个长曝光平均值扩展为沿扫描轨迹的一系列亮度变化约束。这是联合结果比 APS-only 更清楚的根本原因。

## 8. 为什么不能把近端芯斑内部位置当作远端亚像素

当前 simulator 中，一根纤芯只传递一个随时间变化的标量强度。近端一个芯斑覆盖的多个 DAVIS pixels，只是同一纤芯信号的不同固定增益读出。

因此代码对每根纤芯选择 4 个可靠 pixels，但在事件损失之前先在一芯内部平均，保证一根纤芯仍然只算一个独立物理通道。

这些 pixels 可以降低读出误差，但不能被解释为 4 个远端空间采样点。重建中的额外空间信息来自已知远端运动，而不是来自近端圆形芯斑内部的位置。

## 9. 当前结果的分辨率边界

当前轨迹只有水平方向，总位移为 4.5 um，恰好约为一个纤芯间距。因此新增采样相位主要出现在水平方向。

当前结果可以说明：

- 已经生成连续、显著抑制蜂窝纹理的远端 frame；
- 事件相对 APS-only 提高了水平边缘和条纹恢复能力；
- 当前数据支持方向性超分辨。

当前结果不能说明：

- 已经实现各向同性二维超分辨；
- 可以恢复被 2.9 um 芯孔径完全截止的空间频率；
- 近端芯斑内部 pixels 提供了独立远端亚像素；
- exact-model 仿真的结果可以不经标定直接迁移到真实光纤。

如果需要提高二维各向同性分辨率，后续仿真和实验应使用非共线二维轨迹，例如水平加垂直扫描或小圆轨迹。
